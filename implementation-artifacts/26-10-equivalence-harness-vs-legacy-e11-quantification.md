# Story 26.10: Equivalence Harness vs Legacy E11 Quantification

**Status:** backlog
**Epic:** E26 — Agent-Driven Ingestion & Analysis
**Points:** 3
**Type:** integration + ops
**Dependencies:** S26.03 (workflow live), legacy E11 quantification path still operational
**Blocks:** safe retirement of legacy E11 quantification (required before 11-22)
**Created:** 2026-05-15
**Source:** E26 epic §S26.10

## Story

As **Operator Ivan responsible for the cutover from legacy E11 to SirmaAI agent-driven quantification**,
I want **a 50-opportunity equivalence harness that runs both paths in parallel for one sprint and surfaces divergence**,
so that **I can prove the new path doesn't silently regress quantification quality before declaring legacy retired**.

## Acceptance Criteria

1. Author a 50-opportunity validation set committed at `services/client-api/tests/data/sirmaai-baselines/v1/quantification-equivalence-set-v1.json`. Mix of historical Pro+ tenant opportunities (anonymised) — same source pool as quantifier baseline (S26.02) + 35 additional.
2. **Equivalence runner** (Celery task `run_quantification_equivalence_eval`) executes each opportunity through:
   - Legacy E11 path: `AiGatewayClient.run_agent("budget_builder" + relevance scoring chain)`.
   - New path: `opportunity-analysis-v1` workflow (S26.03) with `analysis_type=quantification`.
3. **Delta report** persisted at `eusolicit-docs/test-artifacts/quantification-equivalence-report-{date}.md`:
   - Per-opportunity rows: legacy estimate, new estimate, delta (effort + EV), agent recommendation.
   - Aggregate columns: mean error, median error, max divergence, classification of "improvement" (new closer to actual) vs "regression" (new further from actual).
4. **Run cadence**: 1 sprint (2 weeks) of parallel running. Daily eval-run cycle.
5. **Sign-off**: human reviewer (PM + Murat TEA) accepts new path BEFORE the orchestrator can flip `opportunity-analysis-v1` to 100% rollout per S26.03 staged-rollout gate.
6. **Output report includes**: divergence > 25% rows flagged; top-5 by error; recommended prompt tweaks.
7. **Pre-retirement gate**: 11-22 (E11 endpoint internal call-path swap to SirmaAI) cannot land without this story signing off.
